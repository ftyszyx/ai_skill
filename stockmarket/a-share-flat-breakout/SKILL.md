# A 股横盘放量突破

使用本 skill 运行一个技术预警：识别“窄幅横盘平台 -> 突然放量突破 -> 次日确认”的形态。原型来自 605186 在 2026-05-11 和 2026-05-12 前后的走势。

## 工作流

1. 在用户的股票工作区运行 `scripts/scan_flat_breakouts.py`。优先使用当前目录最新的 `a_share_*_all*.json` 作为股票池；如果没有本地股票池文件，脚本会回退到东方财富列表接口。
2. 每日收盘后扫描最新 K 线：

```powershell
python C:\Users\zhangyuxin\.codex\skills\a-share-flat-breakout\scripts\scan_flat_breakouts.py --max-results 60
```

3. 指定日期回测或验证：

```powershell
python C:\Users\zhangyuxin\.codex\skills\a-share-flat-breakout\scripts\scan_flat_breakouts.py --date 2026-05-11 --watch 605186 --max-results 60
```

4. 打开 `output/breakout_scan/flat_breakouts_YYYYMMDD.md` 报告，总结候选股。说明这些是预警候选，不是自动买入建议。

## 信号模型

默认条件：

- 平台窗口：30 个交易日，至少 20 个有效交易日。
- 横盘压缩：平台高低点振幅 <= 13%，收盘价变异系数 <= 3%。
- 启动前量能安静：平台内最大单日成交量 <= 平台平均成交量 2.2 倍。
- 突破日：涨幅 >= 7%，成交量 / 平台平均量 >= 2 倍，换手率 >= 2%，成交额 >= 8000 万元。
- 605186 风格容忍：如果窄平台后出现接近涨停或涨停的启动日，即使还没有收盘突破 90 日高点，也可以先进入预警。
- 次日确认：次日守住突破日收盘附近，交易活跃，最好继续刷新高点并出现巨量。

脚本输出两类信号：

- `day1_breakout`：第一天启动。
- `day2_confirmed`：第二天放量确认。

## 解读原则

优先关注：

- 平台越窄、收盘波动越低越好。
- 首日量比超过 3 倍，或次日量比达到 6-10 倍以上。
- 收盘靠近日内高位，而不是长上影冲高回落。
- 换手足够强，但此前没有连续多天大涨透支。
- 有真实催化：题材、业绩、订单、政策、板块强度、机构关注等。

提醒用户注意误报：

- 新闻刺激的一日脉冲可能很快失败。
- 高换手叠加长上影，可能是派发而不是吸筹。
- ST、退市、新股、北交所、科创板涨跌幅规则不同，只有用户要求时才纳入。
- 输出是候选池，适合人工复核，不是自动交易规则。

## 常用参数

- `--date YYYY-MM-DD`：扫描历史某个交易日。
- `--watch 605186 603xxx`：强制纳入指定代码，适合验证。
- `--max-base-range-pct 10`：收紧横盘要求。
- `--min-breakout-pct 9`：只关注接近涨停或涨停启动。
- `--min-volume-ratio 3`：提高首日放量要求。
- `--include-star`：纳入科创板。
- `--include-bj`：纳入北交所。
- `--universe-file PATH`：使用指定本地 A 股股票池 JSON。
- `--sample N`：快速抽样测试。

## 回复要求

汇报结果时包含：

- 报告路径。
- 是否发现 605186 风格的首日启动或次日确认信号。
- 前排候选股的代码、名称、信号类型、日期、得分、涨幅、换手率、量比、平台振幅。
- 简短交易观察：例如“明天看确认”“已经确认”“涨幅过大，风险偏高”。
